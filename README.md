
Para correr el proyecto localmente, sigue estos pasos:

# Prerrequisitos
Asegúrate de tener instalado Node.js (versión 16 o superior):
```bash
node --version
```

# Instalación y Ejecución

Abre una terminal en la carpeta del proyecto

# Instala las dependencias:
```bash
npm install
```

# Ejecuta el proyecto en modo desarrollo:
```bash
npm run dev
```

Abre tu navegador en la URL que te muestre la terminal (generalmente `http://localhost:5173` o similar)
